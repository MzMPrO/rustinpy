Работаем по скиллу spec-first (роль Строитель), закрытие этапа. Комментарий пользователя: $ARGUMENTS

1. **Тесты.** Запусти линтер и ВСЕ тесты командами из `.claude/spec-first.json`, с покрытием (`--cov`). Красное чини. Тесты не ослабляй: без удаления assert, без skip/xfail и без подгонки ожиданий. Найди и перечисли все `skip`/`xfail` в `tests/` — каждый должен быть записан как долг с причиной.
2. **AC.** Для каждого AC этапа убедись, что есть тест с его ID и он зелёный, и отметь `[x]`. Ручные AC `(ручная)` отмечай, только если пользователь подтвердил проверку. Остальные вынеси в чек-лист ручной проверки.
3. **Спеки.** Отметь `[x]` выполненные пункты плана. Если закрыты все AC фичи или всего MVP — поставь статус ГОТОВО. Хук перепроверит AC, тесты и линтер; если он заблокировал — исправь причину.
4. **PROGRESS.md.** Допиши в КОНЕЦ запись по формату файла: задание, сделано, тесты (цифры), спеки, решения, долги, ручная проверка, дальше.
5. **CLAUDE.md.** Перезапиши «Текущее состояние» (не больше 15 строк). При необходимости обнови «Команды» и «Соглашения по коду».
6. **DECISIONS.md.** Добавь решения этой сессии.
7. **Архив.** Если в PROGRESS.md больше ~300 строк — перенеси старые записи в `docs/history/`.
8. **Git.** `git status` → коммит с сообщением `тип(область): …` и ссылкой на задание и AC в теле → `git push`. Pre-push хук прогонит тесты. Если push упал — чини, не обходи.
9. **Отчёт.** Выведи блок «📦 Отчёт для архитектора» (формат — `references/builder.md` скилла) и отдельно «🧪 Ручная проверка» на 1–5 пунктов. Напомни пользователю нажать Sync у репозитория в claude.ai Project, если он работает с архитектором.
