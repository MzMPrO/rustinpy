## Workflow (spec-first) — обязательно

Роли: **Архитектор** (claude.ai Project) составляет ТЗ и присылает задания. **Строитель** (Claude Code) реализует. Общая память — этот репозиторий.

1. **Код только по утверждённой спеке:** `docs/SPEC.md` (MVP) или `docs/features/NNN-*.md`. Утверждает только пользователь, словом «утверждаю». Хук блокирует запись кода без утверждения.
2. **Задание от архитектора** (`# Задача NNN · …`) — сначала сохрани дословно в `docs/handoff/NNN-slug.md`. Противоречит спеке — спроси, не выполняй молча.
3. **Тесты — часть этапа.** Сначала красный тест, потом код. У каждого AC есть тест с его ID (`test_ac_07_…` или «AC-07» в докстринге). Тесты не ослаблять: без удаления assert, без skip/xfail без согласия пользователя.
4. **Нашёл то, что меняет поведение** — остановись, спроси, обнови спеку. Архитектурные решения — в `docs/DECISIONS.md`.
5. **Git:** небольшие коммиты `тип(область): …`, push после каждого `/done`. Никаких `--no-verify`, force-push, `reset --hard`. Секреты только в `.env`.
6. **После этапа — `/done`:** все тесты и линтер зелёные → AC отмечены → PROGRESS.md → «Текущее состояние» ниже → DECISIONS.md → commit + push → «Отчёт для архитектора» и чек-лист ручной проверки.
7. **Не обходи хуки** через Bash или другие имена файлов. Заблокировало — объясни пользователю, чего не хватает.
